# 🤖 AI Life Decision Simulator

An AI-powered decision-making chatbot that helps users analyze life choices and receive structured guidance in real time.

Built using Flask, Groq API, HTML, CSS.

---

## 🚀 Features

- AI-generated decision guidance
- Smart and concise responses
- Multiple categories:
  - Career
  - Money
  - Relationship
  - Business
  - Lifestyle
  - Investment
- Interactive dark-themed chat interface
- Real-time API integration
- Responsive frontend UI

---

## 🛠️ Tech Stack

- Python
- Flask
- Flask-CORS
- Groq API
- HTML
- CSS
- JavaScript
